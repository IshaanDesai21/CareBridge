# CareBridge

## Overview

CareBridge is a comprehensive care management platform designed to connect caregivers, patients, and healthcare providers.

## Project Structure

- `docs/` - Project documentation
- `backend/` - Backend services and API
- `dashboard/` - Web dashboard
- `ios/` - iOS application
- `shared/` - Shared resources and utilities
- `assets/` - Project assets (images, icons, etc.)
