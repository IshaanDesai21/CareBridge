## How to Update This Changelog

When making changes:

1. Add entries under the `[Unreleased]` section
2. Group changes by type: Added, Changed, Deprecated, Removed, Fixed, Security
3. Include a brief description of each change
4. Link to relevant PRs or issues if applicable
5. When releasing, move items from Unreleased to a new version section

Example entry:
```markdown
### Added
- New voice assistant feature (#123)
- Support for medication reminders (#124)
```
